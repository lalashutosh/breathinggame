Name pivots: "Body", "Head", and legs "Leg0".."Leg3" (pivot at top so rotation.x swings them).

   Trotting leg swing, body bob, head bob; `graze` 0..1 lowers the head to the grass.

Only `Node3D`, `MeshInstance3D` and built-in resources. Must run in Godot 4.4+. Don't use `@tool`. Cache shared materials in static vars to avoid duplicates.
